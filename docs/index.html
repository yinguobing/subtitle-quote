将聊天文本渲染为微信风格的打字机短视频。

快速开始 GitHub
功能特性

为内容创作者打造的
视频生成工具

从纯文本到精美视频，每一步都精心打磨

打字机逐字淡入

每个字符独立控制 alpha 通道，最近 N 个字符平滑渐变，模拟真实的打字机效果，非简单的逐字弹出。

微信风格布局

暗色模式背景、圆形头像、对语气泡，完美还原聊天界面美学。左/右气泡自动适配，支持自定义头像。

专业视频输出

1920×1080 h264/mp4，兼容所有播放器。可选透明背景 qtrle/mov，无缝接入 DaVinci Resolve 后期流程。

批量渲染

将整个对话脚本写入文本文件，一键生成多段独立视频。自动编号输出，适合内容矩阵批量生产。

完全可配置

字体、字号、颜色、间距、气泡圆角、打字速度——所有视觉参数开放配置，匹配你的品牌风格。

零临时文件

帧数据通过 pipe 直接喂给 ffmpeg，不落盘。纯内存渲染，生成速度快，不污染文件系统。

快速开始

三行命令，即刻生成

Python 3 + Pillow + ffmpeg，开箱即用

安装依赖 
# 安装 Python 依赖
pip install Pillow

# 确保 ffmpeg 已安装
ffmpeg -version
单条消息 
# 生成单条聊天视频
python3 subtitle_quote.py "国冰: AI 时代，你准备好了吗？" -o quote.mp4

# 指定头像 + 右侧气泡（模拟自己发送）
python3 subtitle_quote.py "国冰: 你好" -o quote.mp4 --avatar avatar.jpg --right
批量渲染 
# quotes.txt — 每行一条对话
国冰: AI 时代，你准备好了吗？
小明: 准备好了！
国冰: 那就开始吧

# 批量生成，自动编号输出
python3 subtitle_quote.py quotes.txt -o output_dir/ --batch
# → output_dir/001.mp4, 002.mp4, 003.mp4
配置参考

命令行参数 & 可配置常量

灵活的配置系统，从命令行到源码级定制

CLI 参数 默认值 说明
input — 文本或文件路径（格式：名字: 内容）
-o, --output output 输出路径（单条模式自动补 .mp4）
--avatar — 头像图片路径（不指定则生成首字母头像）
--right — 头像在右侧（模拟自己发送，气泡变绿）
--width 1920 画布宽度
--height 1080 画布高度
--fps 24 帧率
--speed 2 每字符帧数，越大打字越慢
--batch — 批量模式：每行生成独立视频
--transparent — 透明背景（输出 qtrle/mov）
源码常量 默认值 说明
TEXT_SIZE 48 气泡文字大小
NAME_SIZE 32 名字文字大小
AVATAR_SIZE 100 头像尺寸
BUBBLE_RADIUS 16 气泡圆角半径
MAX_WIDTH 860 气泡最大宽度
FADE_SPAN 5 淡入窗口（最近 N 个字符同时渐变）
LETTER_SPACING 3 字符间距 (px)
LINE_GAP 30 行间距 (px)
